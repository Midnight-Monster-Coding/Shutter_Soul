🧹 Clean Up Duplicate Accounts

⚠️ WARNING: This script will permanently delete duplicate user accounts from your Firebase database. It will keep only the document where docId === uid for each user. Make sure you have a backup before proceeding!

What this script does:

  • Scans all documents in the 'users' collection
  • Identifies duplicate accounts (same UID with different document IDs)
  • Keeps the primary account (where document ID = UID)
  • Deletes all duplicate accounts
